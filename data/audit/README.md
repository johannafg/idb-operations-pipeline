# Audit excerpt

`microdata_audit.json` here is a **50-operation excerpt**, not the full audit.

The complete audit for the 2,581-operation panel is 23 MB, which is impractical
to browse on GitHub and heavy to carry in every clone. It is regenerated by
Stage 3 with `src/build_microdata_panel.py`, and `data/processed/` holds the
full panel it produced.

The excerpt is a reproducible draw (seed 20260927) chosen to show the design
rather than only its successes. It deliberately includes operations with no
published loan proposal, operations where a citation could not be resolved to a
source document, operations where the contamination flag fired because a quote
does not name the operation, and operations from the pre-2003 numbering scheme.

Each entry holds, per field: the value, its status (`found`, `stated_absent` or
`not_stated`), the paragraph citation, the verbatim supporting quote, the
resolved source document, and the two contamination flags.
